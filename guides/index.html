从现象出发，最快找到答案

  1. VS Code Remote-SSH 提示超时或拒绝连接：从 SSH 分层排障清单开始，先检查虚拟网络、端口，再检查身份验证。
  2. GitHub 推送成功但网站没有更新：参考 双发布验收流程，分别排查 CI、Pages、域名和后台服务。
  3. 网页正常但百度搜索爬虫被拒绝：先读 Cloudflare 抓取规则排障，再把当前公网 robots.txt 复制到 离线检查器对照。
